# data-analysis-marketing-bank-campaign
Analiza el desempeño de una campaña de marketing directo de una entidad financiera orientada a la captación de inversiones a plazo fijo. A través de un proceso de análisis exploratorio de datos (EDA) y limpieza de datos, se procesaron más de 41,000 registros para identificar los factores críticos que impulsan la conversión de clientes.

Objetivos:

•	Determinar la efectividad de la campaña (tasa de conversión).
•	Identificar el perfil del cliente que aceptó realizar inversiones a plazo fijo.
•	Establecer indicadores (KPI) relevantes que influyen en la aceptación del servicio promocionado.
•	Determinar aspectos relevantes que influyen en la aceptación del servicio promocionado.
•	Crear un dashboard con insights accionables y relevantes para la toma de decisiones.

Proceso de análisis:
• Validación y limpieza (data cleaning) de datos
• Análisis exploratorio de datos (EDA)
• Evaluación del método de imputación
• Creación de gráficos
• Creación de insights
• Visualización de información a través de la construcción de un dashboard en Power BI
• Redacción de informe con la interpretación de los hallazgos encontrados.

Conjuntos de datos: 
Los conjuntos de datos contienen información demográfica y financiera de los clientes del banco, así como también información de las interacciones (llamadas) como duración de la llamada,
contactos previos y cantidad de contactos previos, aceptación del producto, etc.

Informe:
Este informe detalla el análisis de efectividad de una campaña de marketing directo para captación de inversiones a plazo fijo en una entidad financiera. Mediante el procesamiento de 41,188 registros, se realizó una limpieza de datos que eliminó valores nulos y aplicó la técnica de capping (se probaron dos métodos de imputación) para tratar outliers numéricos. Los resultados principales muestran una tasa de conversión del 11.25%, identificando también el perfil ideal de cliente o "Buyer Persona". El análisis de interacción resalta los resultados  del medio de contacto y duración óptima de las llamadas. Finalmente, se presenta un dashboard en Power BI con indicadores clave (KPI) e insights orientados a optimizar la toma de decisiones estratégicas en futuras campañas

Estructura:

Datos/: CSV con datos de la última campaña realizada

Documentos/: informe en formato pdf
Tecnologías: Python, Pandas, Matplotlib, Seaborn, Power BI.
